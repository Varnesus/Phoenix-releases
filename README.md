# Phoenix – pliki aktualizacji

Publiczne repozytorium wydań programu Phoenix. Zawiera wyłącznie pliki do pobrania (zakładka Releases):
`manifest.json` (podpisany), `phoenix-X.Y.Z.html` i pełną paczkę `Phoenix-win32-x64.zip`.
Program sprawdza adres `https://github.com/Varnesus/Phoenix-releases/releases/latest/download/manifest.json`.
Wydania tworzy automat z prywatnego repozytorium; nie wrzucaj tu niczego ręcznie.
